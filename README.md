## Summary
This is a Super Simple Math Tutor for young children. 

The program:

-Displays the program header

-Displays some silly and fun math jokes

-Gets the users name

-Welcomes the user to the math tutor

-Gives the user a simple math question

-Gets the user's answer

-Says goodbye to the user
